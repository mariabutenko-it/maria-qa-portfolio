# Qure — Project Analysis

## Project Overview

Qure is a healthcare mobile application that allows users to search for medications, place orders, manage prescriptions, receive bonuses, and maintain a personal health profile.

The project consists of several components:

- Mobile application (Android / iOS)
- Backend API
- Web Admin Panel
