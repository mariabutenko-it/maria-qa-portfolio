# 07. API Testing

## Purpose

This folder contains API testing documentation for the Qure project.

The documentation describes:

- API testing strategy
- Endpoint analysis
- Authentication flow
- Request validation
- Response validation
- Error handling
- Test scenarios
- API automation preparation

---

# Objectives

API testing is performed to verify:

- Business logic
- Data integrity
- Authentication
- Authorization
- Performance of critical endpoints
- Error handling
- Backend stability

---

The following modules will be covered:

- Authentication
- User Profile
- Product Catalog
- Categories
- Search
- Shopping Cart
- Orders
- Payment
- Bonuses
- Medication Reminders
- Notifications
- User Settings

---

# API Test Types

## Functional Testing

Verification of:

- Request body
- Response body
- Business logic
- Required fields

---

## Negative Testing

Verification of:

- Invalid parameters
- Missing fields
- Invalid tokens
- Unauthorized access
- Incorrect request format

---

## Security Testing

Verification of:

- Authentication
- Authorization
- Access permissions
- Protected endpoints

---

## Response Validation

Verification of:

- Status Code
- Response Time
- JSON Structure
- Data Types
- Required Fields
