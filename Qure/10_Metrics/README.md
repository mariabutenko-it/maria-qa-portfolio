# 10. Metrics

## Purpose

This folder contains QA metrics used to monitor product quality, testing progress, and automation coverage throughout the Qure project.

The goal of these metrics is to support informed release decisions and continuously improve the QA process.

---

# Quality Metrics

The following quality indicators are monitored:

- Test Case Coverage
- Test Execution Progress
- Defect Distribution
- Defect Severity
- Defect Priority
- Defect Leakage
- Reopened Defects
- Automation Coverage
- Regression Stability
- Release Readiness

---

# Test Coverage

Measures the percentage of implemented functionality covered by test cases.

Examples:

- Functional Coverage
- Regression Coverage
- Smoke Coverage
- Automation Coverage

---

# Test Execution

Tracks testing progress.

Metrics include:

- Total Test Cases
- Executed Tests
- Passed Tests
- Failed Tests
- Blocked Tests
- Not Executed Tests

---

# Defect Metrics

Monitored indicators:

- Total Defects
- Open Defects
- Closed Defects
- Critical Defects
- High Priority Defects
- Average Resolution Time
- Defects by Module

---

# Defect Distribution

Defects are categorized by functional module.

Examples:

- Authentication
- Cart
- Orders
- Profile
- Medication Reminders
- Notifications
- Payment
- Catalog

This analysis helps identify high-risk areas and prioritize regression and automation efforts.

---

# Automation Metrics

The following automation indicators are planned:

- Automated Test Cases
- Automation Coverage
- Smoke Automation Coverage
- Regression Automation Coverage
- Test Execution Time
- Pass Rate
- Failure Rate

---

# Release Metrics

Each release will be evaluated using:

- Smoke Test Result
- Regression Result
- Open Critical Bugs
- Open High Priority Bugs
- QA Approval Status
