# Qure Mobile Application

## Project Overview

Qure is a mobile application for Android and iOS platforms.

The application provides:
- user authentication
- medicine ordering flow
- profile management
- payments
- reminders
- health-related features

## QA Activities

Performed QA activities:

- Functional testing
- Regression testing
- Smoke testing
- Test case creation
- Bug reporting
- Test documentation
- Automation preparation
