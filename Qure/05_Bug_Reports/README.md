# 05. Bug Reports

## Purpose

This folder contains bug reports, defect analysis, and QA observations identified during testing of the Qure mobile application.

The documentation is intended to:

- record discovered defects;
- classify issues by severity and priority;
- analyze recurring problems;
- identify high-risk functional areas;
- support regression planning and automation prioritization.

---

## Bug Report Structure

Each bug report should include:

- Bug ID
- Summary
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Attachments (screenshots, videos, logs)
- Status
