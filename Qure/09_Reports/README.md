# 09. Reports

## Purpose

This folder contains QA reports created during testing of the Qure mobile application.

The reports provide visibility into testing progress, product quality, defect trends, and release readiness.

---

# Report Types

The following reports are planned:

- Daily QA Report
- Smoke Test Report
- Regression Test Report
- Sprint Test Report
- Release Readiness Report
- Automation Execution Report
- API Testing Report
- Test Summary Report

---

# Daily QA Report

Purpose:

- Track daily testing activities
- Monitor completed tasks
- Record identified defects
- Highlight blockers and risks

Typical content:

- Completed testing
- New defects
- Fixed defects verified
- Planned activities
- Risks and blockers

---

# Smoke Test Report

Purpose:

Verify that the application is stable after a new build or deployment.

Includes:

- Build version
- Environment
- Executed scenarios
- Pass / Fail status
- Critical issues

---

# Regression Test Report

Purpose:

Summarize the results of regression testing before a release.

Includes:

- Scope
- Number of executed test cases
- Passed / Failed tests
- Blocked tests
- Open defects
- Release recommendation

---

# Sprint QA Report

Purpose:

Summarize QA activities during a sprint.

Includes:

- Tested stories
- Test coverage
- Defects found
- Regression status
- Automation progress

---

# Release Readiness Report

Purpose:

Evaluate whether the application is ready for production release.

Includes:

- Smoke testing status
- Regression status
- Critical defects
- High priority defects
- Known issues
- QA recommendation

---

# Automation Report

Purpose:

Summarize automated test execution.

Includes:

- Number of executed tests
- Passed tests
- Failed tests
- Execution time
- Environment
- Test logs

---

# API Testing Report

Purpose:

Summarize API validation results.

Includes:

- Tested endpoints
- Passed requests
- Failed requests
- Response validation
- Performance observations

---

# Test Summary Report

Purpose:

Provide an overall summary of the testing cycle.

Includes:

- Scope
- Test execution statistics
- Defect statistics
- Risks
- Recommendations
- Final QA decision
